LEVEL 02 — SCANNINGREWARD +150 XP // BADGE: PORT DETECTIVECOMPLETE

Scanning: Mapping the Doors

  • Port — a numbered door a service listens behind (0–65535).Port 22 usually means SSH, 80 means web.
  • Service — the program answering at that door.FTP, SSH, HTTP, databases…
  • Version — which edition of the service.Versions turn "a door" into "a known, documentable lead".
  • TCP vs UDP — two delivery styles.TCP = registered mail (confirmed). UDP = postcards (fast, unconfirmed). Beginners start with TCP.

WHY SCAN? You can't defend or assess what you can't see. Scanning converts a mystery box into an inventory — the foundation of everything after this.

LEVEL 03 — ENUMERATIONREWARD +200 XP // BADGE: ENUMERATION EXPERTCOMPLETE

Enumeration: From Map to Leads

  • Service enumeration — ask each service its story.Banners, shares, users, configs — FTP anonymous? SMB shares listed?
  • Web enumeration — walk the site like a cartographer.Pages, forms, endpoints, plus directory discovery (Gobuster/Dirsearch on in-scope targets only).
  • SSH / FTP / SMB — three protocols you'll meet today.SSH = remote shell. FTP = file transfer. SMB = Windows file sharing.
  • Version identification — the bridge from scan to vulnerability research.Exact versions are what you search advisories for.
  • Evidence collection — screenshot, log, label.If it isn't captured, it didn't happen.

ENUMERATION LOOP

  1. 1 Pick one service from your scan.
  2. 2 Ask it polite questions (banner/version/features).
  3. 3 Write down exactly what it told you.
  4. 4 Rank it: boring / interesting / hot lead.
  5. 5 Repeat — evidence grows each loop.

◈ CHALLENGE 03 — PRIORITIZE THE ATTACK SURFACE

Turn raw scan results into a prioritized attack surface: pick your top 3 services to enumerate first, most promising lead at the top of your mental list. Then verify.

TAKEAWAY

Scanning finds doors; enumeration learns what's behind them. Prioritize by evidence, not vibes.

Hermes Agent is the open-source, self-improving AI agent by Nous Research — your co-pilot for this lab. Six beginner-proof steps below. Commands verified against official sources on 2026-09-29 — re-verify before every delivery; agent tooling moves fast.

GROUND RULES + PREREQUISITES ~30 SEC TO READ

Open Terminal (or iTerm / Warp). Download, read, run:

Shortcut (same official script, one line):

2

INSTALL — WINDOWS TWO WAYS

Way 1 — WSL2 (recommended): in an admin PowerShell run wsl --install → restart → open the new Ubuntu app → run the exact same commands as macOS, ending with source ~/.bashrc.

Way 2 — native Windows (early beta): run this in PowerShell (not cmd):

"Early beta" = fewer road miles: e.g. the browser dashboard's chat terminal pane is still WSL2-only anyway. When in doubt, use WSL2.

PROVE THE INSTALL WORKED

From Observation to Finding

"Port 21 is open" is trivia. A finding is trivia transformed into a decision-making tool: evidence, risk, impact, and a fix.

“Port 21 is open.”

RAW OBSERVATION — NO VALUE YET

➜
FINDING
Outdated FTP service (vsftpd 2.3.4) exposed on the authorized lab target.
EVIDENCE
Terminal capture of the service returning its exact version on connection; screenshot labeled EV-01.
RISK
High — this version carries a publicly documented, remotely triggerable weakness.
IMPACT
An attacker could gain unauthorized access to the host and its data.
REPRODUCTION
1) Connect to port 21 on the in-scope lab target. 2) Observe the version in the service banner.
RECOMMENDATION
Upgrade or replace the FTP service; restrict it to required hosts only; retest to confirm.
TAKEAWAY

Clients don't pay for open ports — they pay for explained risk and a path to fix it. Write for the reader who must act.
