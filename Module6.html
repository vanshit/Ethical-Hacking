02 / Wireless foundations

Same airwaves. Better protection.

Wi-Fi security controls who joins a wireless network and protects data on the radio link from reading or tampering.

CLICK TO EXPLORE
Two different jobs
01

Authentication

“May you join?” Verifies a device or user through a shared secret or individual credentials.

02

Encryption

“Who can read this?” Scrambles radio-link data using negotiated keys. Integrity protection also helps detect changes.

Wi-Fi encryption is not end-to-end protection. Use HTTPS too. A lock icon is not proof that a site is trustworthy.
Why the evolution? Weak cryptography, key/nonce reuse and design flaws weakened older protocols. Newer standards improve protection, but implementation bugs, poor passwords and misconfiguration still matter.

Field notes: a stronger Wi-Fi baseline
  • Prefer WPA3-Personal; use WPA2-AES/CCMP if compatibility requires it. Avoid WEP, WPA/TKIP and legacy mixed modes.

  • Organizations can use Enterprise authentication with individual identities and certificate validation.

One sample can fit several labels.

  • Unwanted adware may be a PUA/PUP rather than confirmed malware.

Conceptual telemetry view, not physical routing: endpoints and network devices can also send logs directly to the SIEM.
01 / Firewall FILTER
Applies allow/deny policies to network traffic using addresses, ports, protocols and often connection state or application context. Example: permit approved web access, deny an unapproved inbound service. Allowed does not automatically mean safe.
02 / IDS DETECT + ALERT
An Intrusion Detection System inspects activity for suspicious signatures or behaviors, then alerts. A passive IDS does not itself sit inline to block that traffic. Analysts validate the alert.
03 / IPS DETECT + MAY BLOCK
An Intrusion Prevention System is typically inline. It can detect and potentially drop matching traffic according to policy. Tune rules carefully: a false positive can disrupt legitimate work.
04 / SIEM CONNECT THE DOTS
Security Information and Event Management centralizes evidence.
  • Collect logs from endpoints, identity systems and network devices.
  • Normalize different log formats into consistent fields.
  • Correlate related events across hosts and time.
  • Alert on rules or unusual patterns.
  • Support analyst investigation with searches and timelines.
